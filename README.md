# chat.example.com — Open WebUI для Hermes

Веб-чат із Hermes Agent у браузері: список розмов, папки, пошук, стрімінг відповідей.
Це [Open WebUI](https://github.com/open-webui/open-webui), підключений до вбудованого
OpenAI-сумісного API-сервера Hermes (`127.0.0.1:8642`, увімкнено через `API_SERVER_ENABLED`
в `~/.hermes/.env`). Hermes виконує запити з усіма своїми інструментами на mini.

## Як запускається

Роутер при першому запиті до `chat.example.com` виконує `npm start` → `./start.sh`, який піднімає
`open-webui serve` на порту з `PORT`. Старт займає ~6 с (перший після встановлення — ~80 с,
бо докачує модель для вбудованого пошуку по файлах). Після 30 хв без запитів роутер зупиняє процес.

Open WebUI встановлено як інструмент uv (Python 3.11): `~/.local/bin/open-webui`.
Оновлення: `uv tool upgrade open-webui`, потім `curl -X POST http://127.0.0.1:8000/_restart/chat`.

## Дані й секрети

- `data/` (не в git): база SQLite з користувачами та чатами, завантажені файли, `.webui_secret_key`
  (підпис JWT; якщо видалити, усіх розлогінить).
- Ключ до Hermes `start.sh` читає з `~/.hermes/.env` (`API_SERVER_KEY`), окремої копії немає.

## Доступ

Перший створений акаунт є адміністратором. Реєстрація вимкнена; нові користувачі (якщо увімкнути)
отримують роль `pending` і чекають схвалення в Admin Panel → Users. Скинути пароль: Admin Panel →
Users → редагувати користувача.

## Що навмисно вимкнено

Автогенерація назв чатів, тегів, підказок-продовжень, автодоповнення і пошукових запитів.
Кожен такий «службовий» запит у Open WebUI є повноцінним запуском агента Hermes з інструментами,
тож вони плодили б зайві сесії й навантаження. Ці значення стали дефолтом при першому старті
і зберігаються в базі; змінити можна в Admin Panel → Settings → Interface.

## Обмеження схеми через API-сервер

- Open WebUI щоразу надсилає всю історію чату; сесії тут окремі від Telegram/TUI/панелі Hermes.
- Запити на підтвердження дій (approvals) у цей інтерфейс не доходять: якщо Hermes потребує
  дозволу, запуск зависне або буде заблоковано. Для таких задач краще Telegram або `hermes` у терміналі.
- Довгий ресерч тримає одне з'єднання; стрім живе завдяки keepalive Hermes кожні 10 с,
  таймаут клієнта Open WebUI піднято до 1 години (`AIOHTTP_CLIENT_TIMEOUT`).
